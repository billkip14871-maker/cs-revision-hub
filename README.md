# CS Revision Hub v16

A production-oriented Computer Science learning platform for Kenyan and international university students.

## v16 features
- SEO-ready Next.js pages
- Course/topic URLs
- Search
- Source-grounded AI/RAG architecture
- Verified-content workflow
- Quiz API
- Student progress API
- YouTube video integration fields
- Supabase authentication/database
- Sitemap and robots configuration
- Shareable URLs
- Admin verification workflow
- Mobile responsive UI

## Deployment
Deploy to Vercel, connect Supabase, and add server environment variables.
Never commit `.env.local`, OpenAI keys, or Supabase service-role keys.

## Academic verification
A note is not labelled "verified" merely because a university teaches the topic. Verification should record the official source, curriculum version, reviewer and rights status.
